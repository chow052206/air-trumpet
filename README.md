# 🎺 Air Trumpet

A browser-based virtual trumpet controlled using hand gestures.

## Features

- 📷 Real-time webcam detection
- ✋ Hand tracking with MediaPipe
- 🤏 Pinch gesture detection
- 🎵 Trumpet sound playback (in progress)

## Tech Stack

- HTML
- CSS
- JavaScript
- MediaPipe Hand Landmarker
- Web Audio API / Tone.js
